# Todo List App with Local Storage

This is a simple Todo List app built with React. It allows you to add, complete, and delete todos. The app uses **localStorage** to persist data, so your tasks remain even after a page refresh.

## Features
- Add a new todo item.
- Mark todo items as completed.
- Clear completed todos.
- Persist todos in local storage so they are saved even after page refresh.

## Installation

1. Clone the repository to your local machine:

   ```bash

2. Navigate to the project directory:
   ```bash

3. Install dependencies:
